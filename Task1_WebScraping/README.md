# CodeAlpha Internship – Task 1: Web Scraping

## Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The objective of this task is to collect useful information from a public webpage using Python web scraping techniques and convert the collected information into a structured dataset.

For this project, data was collected from **Books to Scrape**, a website designed for practicing web scraping.

## Objectives

* Extract data from a public webpage.
* Understand the HTML structure of a webpage.
* Use Python libraries for web scraping.
* Navigate through multiple webpages.
* Create a custom dataset.
* Clean and organize the collected data.
* Save the final dataset in CSV format.

## Technologies Used

* Python
* Requests
* BeautifulSoup
* Pandas

## Data Collected

The scraper collects the following information:

* Book Title
* Price
* Rating
* Availability
* Book URL

## Methodology

The project follows these steps:

1. Connect to the website using the Requests library.
2. Download the webpage HTML.
3. Parse the HTML using BeautifulSoup.
4. Identify the required HTML elements.
5. Extract book information.
6. Navigate through multiple pages.
7. Store the collected information in a Python list.
8. Convert the collected data into a Pandas DataFrame.
9. Remove duplicate records.
10. Check for missing values.
11. Save the final dataset as a CSV file.

## Dataset Description

| Column       | Description                     |
| ------------ | ------------------------------- |
| Title        | Name of the book                |
| Price        | Price of the book in pounds     |
| Rating       | Book rating from 1 to 5         |
| Availability | Availability status of the book |
| Book_URL     | URL of the individual book      |
